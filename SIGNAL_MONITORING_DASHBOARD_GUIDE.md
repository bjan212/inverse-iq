# 📊 Signal Monitoring Dashboard Guide

## Overview

The Signal Monitoring Dashboard is a real-time web interface for tracking all generated trading signals, their outcomes, P&L, and AI performance metrics.

## Features

✅ **Real-Time Metrics:**
- Total signals generated
- Win rate percentage
- Average P&L per signal
- Active vs. closed signals
- Signal confidence distribution

✅ **Signal History Table:**
- All signals with timestamps
- Entry/exit prices
- Documented outcomes (win/loss)
- P&L tracking
- Direction (LONG/SHORT)

✅ **Performance Analysis:**
- Win rate by symbol
- P&L by symbol
- Signal count by symbol
- Historical performance tracking

✅ **AI Engine Stats:**
- Total patterns learned
- Trader count
- Model accuracy
- Total AI-generated signals

✅ **Auto-Refresh:**
- Updates every 30 seconds automatically
- Manual refresh button available
- Real-time status indicator

## Understanding the Data

### Signal Status

- **Active** 🟢 - Signal generated, waiting for trade outcome
- **Closed** 🔵 - Signal's outcome has been documented
- **Expired** ⚫ - Signal time window passed without outcome

### Outcome Types

- **Win** ✅ - Signal was profitable (pnl > 0)
- **Loss** ❌ - Signal was unprofitable (pnl < 0)
- **Pending** ⏳ - Trade still open, outcome not yet recorded

### Direction

- **LONG** 📈 - Expected price increase
- **SHORT** 📉 - Expected price decrease

## Using the Dashboard

### 1. Monitor Signal Generation

The dashboard **automatically tracks all signals** generated by the AI engine. As the engine generates new signals, they appear in the table with:
- Signal ID
- Direction and confidence
- Generation timestamp
- Status (active/closed/expired)

### 2. Document Signal Outcomes

When a trade closes, update the outcome via the API:

```bash
curl -X POST http://localhost:3000/api/feedback/signal-outcome \
  -H "Content-Type: application/json" \
  -d '{
    "signalId": "BTCUSDT_1234567_abc",
    "outcome": "win",
    "entryPrice": 45000,
    "exitPrice": 46125,
    "pnl": 500,
    "pnlPercentage": 2.5,
    "duration": 3600
  }'
```

### 3. Track Performance

The dashboard automatically calculates:
- ✅ Win rate (wins / total)
- 💰 Average P&L per signal
- 📊 Performance by symbol
- 🎯 Confidence vs. actual performance

### 4. Monitor AI Learning

Watch the AI Engine Statistics update as:
- More trader data is added (Total Traders increases)
- More signals are documented (Accuracy improves)
- Pattern database grows (Total Patterns increases)

## Troubleshooting

### Dashboard shows "No signals yet"

**Cause:** The AI engine hasn't generated signals yet.

**Solution:**
1. Run the AI engine: `node scripts/bootstrapHybridAI.js`
2. Start generating signals: Call `/api/signals` endpoint
3. Dashboard will auto-populate

### Metrics not updating

**Cause:** Auto-refresh interval or connection issue.

**Solution:**
1. Click "🔄 Refresh Now" button
2. Check browser console for errors (F12)
3. Verify server is running: `curl http://localhost:3000/api/health`

### P&L shows as "-"

**Cause:** Signal outcome hasn't been documented yet.

**Solution:**
1. Call the `/api/feedback/signal-outcome` endpoint
2. Provide entry, exit, and pnl values
3. Dashboard will update within 30 seconds

### No data in symbol performance

**Cause:** No signals have been closed yet.

**Solution:**
1. Generate signals with `/api/signals`
2. Document outcomes with `/api/feedback/signal-outcome`
3. Wait for next auto-refresh (30 seconds)

## Tips & Tricks

### 💡 Quick Performance Check

Check win rate in top metric card:
- > 70% = Excellent
- 60-70% = Good
- 50-60% = Fair
- < 50% = Needs improvement

### 📊 Monitor Symbol Bias

Look at Performance by Symbol:
- If one symbol always loses: Remove it temporarily
- If one symbol always wins: Focus on it
- If balanced: Diversification is good

### 🎯 Track Confidence Accuracy

Compare "Avg Confidence" metric to "AI Accuracy":
- If equal: Confidence matches reality
- If confidence > accuracy: Signals are too optimistic
- If accuracy > confidence: Signals are too conservative

### 📈 Early Warning Signs

Watch for these warning signs:
- 📉 Win rate dropping below 60%
- 💰 Average P&L becoming negative
- 🟡 Total patterns not increasing
- ⏳ High signal expiration rate

## Advanced Usage

### Bulk Signal Upload

Record multiple signal outcomes at once:

```bash
curl -X POST http://localhost:3000/api/feedback/batch \
  -H "Content-Type: application/json" \
  -d '{
    "outcomes": [
      {"signalId": "SIG1", "outcome": "win", "pnl": 100},
      {"signalId": "SIG2", "outcome": "loss", "pnl": -50},
      {"signalId": "SIG3", "outcome": "win", "pnl": 200}
    ]
  }'
```

### Export Signal Data

Get full signal history as JSON:

```bash
curl http://localhost:3000/api/feedback/history?limit=1000 > signals.json
```

### Custom Filtering

Get signals for specific symbol:

```bash
curl http://localhost:3000/api/feedback/history?symbol=BTCUSDT&limit=50
```
