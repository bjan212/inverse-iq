## 📝 Voice & Tone

### **Brand Voice**
- **Intelligent** - Data-driven, analytical, precise
- **Confident** - Assertive, proven, reliable
- **Innovative** - Forward-thinking, cutting-edge
- **Accessible** - Clear, understandable, helpful

### **Writing Style**

#### **Do:**
- ✅ Use active voice
- ✅ Be direct and clear
- ✅ Explain technical concepts simply
- ✅ Show confidence in the AI
- ✅ Use data and numbers
- ✅ Be professional yet approachable

#### **Don't:**
- ❌ Use jargon without explanation
- ❌ Make unrealistic promises
- ❌ Be overly casual
- ❌ Use excessive exclamation marks
- ❌ Guarantee profits
- ❌ Downplay risks

### **Example Phrases**

#### **Good:**
- "8 traders lost $45,000 in similar conditions"
- "92% confidence based on proven patterns"
- "Learn from losses, profit from patterns"
- "AI-powered inverse learning"

#### **Avoid:**
- "You'll definitely make money!"
- "Never lose again!"
- "Secret trading strategy!"
- "Get rich quick!"

## 🌐 Web Design

### **Layout Principles**

#### **Dark Theme**
- Primary background: #0a0e27
- Reduces eye strain
- Professional appearance
- Highlights data effectively

#### **Card-Based Design**
- Clear separation of content
- Easy to scan
- Mobile-friendly
- Scalable

#### **Gradient Accents**
- Purple gradient for brand identity
- Subtle use, not overwhelming
- Consistent across pages
- Premium feel

### **Spacing**
```css
/* Consistent spacing scale */
--space-xs: 4px;
--space-sm: 8px;
--space-md: 16px;
--space-lg: 24px;
--space-xl: 32px;
--space-2xl: 48px;
```

### **Border Radius**
```css
/* Consistent rounding */
--radius-sm: 5px;   /* Small elements */
--radius-md: 10px;  /* Cards, inputs */
--radius-lg: 15px;  /* Large cards */
--radius-xl: 20px;  /* Hero sections */
--radius-full: 50%; /* Circles, pills */
```

## 📱 Responsive Design

### **Breakpoints**
```css
/* Mobile */
@media (max-width: 767px) { }

/* Tablet */
@media (min-width: 768px) and (max-width: 1199px) { }

/* Desktop */
@media (min-width: 1200px) { }
```

### **Mobile-First Approach**
- Design for mobile first
- Progressive enhancement
- Touch-friendly targets (44px minimum)
- Readable text (16px minimum)
